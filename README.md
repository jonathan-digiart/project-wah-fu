# Project Wah Fu

Experimental procedural clay-model rebuild. This repository is being bootstrapped for reviewed development; it does not yet contain a complete estate reconstruction or a public demo.

Work is tracked in issues #1–#5. Implementation will be proposed in draft pull requests. Reference data, legacy assets and private provenance are excluded. No licence has been selected.

GitHub Pages is not enabled by this work. No deployment workflow is included; a public demo requires explicit owner approval of the first procedural rebuild.
