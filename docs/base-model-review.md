# Clay baseline

The owner approved the visual v9 baseline and public publication. This is not survey, terrain, historical reconstruction or walkability certification.

The model retains the accepted site crop. Its boundary line is hidden. The default frontal view and Reset share the same responsive fit; building focus, top view and collision remain available.

Open work: terrain refinement, foundations and ground connections, detailed Wah Mei geometry, contextual building accuracy, and real mobile performance. Record uncertain dimensions explicitly. Add regression tests for observed defects, and lint rules where static checking fits.

Only the sanitized runtime dataset is public. Private source archives, audit samples, photographs, original mesh assets, private repositories and their history are not part of this release.
