# Project Wah Fu

**以 AI 輔助三維重建，記錄香港華富邨的建築、日常風景與社區記憶。**

繁體中文（香港） · [English](README.md)

### 簡介

Project Wah Fu 是一項以香港華富邨為主題的數碼保育實驗，結合三維建模、網頁互動及資料整理，探索如何在社區逐步改變的過程中，記錄其建築形態與生活環境。

項目的長遠目標，是建立可在瀏覽器中探索的三維場景，將樓宇及公共空間與相關照片、文字、聲音和故事連結，讓使用者透過具體位置認識華富邨。

**目前仍處於早期開發階段，尚未提供完整屋邨重建。**

### 背景

華富邨由前香港屋宇建設委員會建築師廖本懷先生負責設計，自 1967 年起分期落成，由 18 座住宅大廈及相關商場、學校、平台與公共空間組成，承載了幾代居民的生活。

隨着分期重建推進，樓宇、公共空間與日常景觀將逐步改變，為相關記錄工作帶來時間上的迫切性。[官方重建進展（2026 年 11 月 2 日）](https://www.news.gov.hk/chi/2026/11/20261102/20261102_174753_450.html?type=ticker)

Project Wah Fu 源於將生成式 AI 應用於社區記錄的探索，並受到「[邨新富華](https://www.facebook.com/WahFuRelocation)」、「[華富一邨民](https://www.facebook.com/profile.php?id=100086308818605)」等 Facebook 專頁的照片與故事啟發。除建築外，亦希望紀錄各種構成屋邨生活的細節。

### 長遠目標

預期範圍包括華富一邨、華富二邨，以及與屋邨生活相連的周邊環境。主要方向包括：

- **空間探索：** 從屋邨全貌到個別樓宇，呈現建築、公共空間及其相互關係。
- **位置與故事連結：** 將照片、文字、聲音、相關報道和社區專頁連結到對應位置。
- **不同時期的記錄：** 在有足夠資料支持時呈現歷史面貌，並標示日期、來源及不確定之處。
- **網頁可用性：** 在視覺細節、載入時間及操作流暢度之間取得平衡。

以上屬於發展目標，尚未全部實現。

### 現階段：程序化模型重建

[公開預覽](https://jonathan-digiart.github.io/project-wah-fu/) · [發布版本](https://github.com/jonathan-digiart/project-wah-fu/commit/348b19d7166fbee2ef01b6fb6bf6b048b3bf5e4b)

早期原型採用政府開放地理及三維數據建立基礎模型，並以參考照片、藉助AI 建構局部建築細節。

項目以 **[Three.js](https://threejs.org)、[TypeScript](https://www.typescriptlang.org) 和 [Vite](https://vite.dev)** 開發程序化模型，由程式配合明確參數生成地形及樓宇形體。工作重點是先核對範圍、比例、位置、方向，以及樓宇與地面的接合，再逐步增加細節。

- 程序化模型的實驗性程式框架已透過 [PR #6](https://github.com/jonathan-digiart/project-wah-fu/pull/6) 合併至 `main`，首個公開預覽已發布。
- 地形、建築形體及地面接合仍需按參考資料修正和驗收。程式測試通過並不代表已準確重現華富邨。
- 程式碼與場景資料分開處理。原始模型、參考照片及舊版素材不會因程式碼發布而自動納入公開版本；公開場景只應包含已完成檢查及獲准發布的內容。
- 公開預覽為開發中的原型。已知限制及後續工作記錄於 [Issues](https://github.com/jonathan-digiart/project-wah-fu/issues)。

### 製作流程與 AI 的角色

項目由創作者制定方向、選取參考資料及審閱成果；AI 代理協助資料整理、程式編寫、模型處理和測試。OpenAI Dots 用於協調及推進相關工作，在工具可用、任務明確的情況下，處理可持續執行的步驟。涉及視覺判斷、資料取捨及版本發布的決定，仍由項目負責人審核。

製作及審閱遵循以下原則：

- **資料依據：** 分開記錄有照片或測量支持的內容、推斷及未知部分。
- **可修正性：** AI 生成結果不作為歷史事實的證據；取得更可靠資料後，重新核對及修正相關細節。
- **分階段驗收：** 先確認空間關係與形體，再增加細節，並分別檢查程式、實際畫面及操作體驗。
- **來源與權利：** 記錄資料來源、日期、署名及使用條件；使用權限尚未確認的素材不納入公開版本。

### 開發進度

工作項目及待確認事項記錄於 [Issues](https://github.com/jonathan-digiart/project-wah-fu/issues)，程式變更透過 [Pull requests](https://github.com/jonathan-digiart/project-wah-fu/pulls) 提交審閱。

近期工作依次涵蓋：

1. 確立座標、比例及場地邊界。
2. 修正程序化地形與樓宇形體。
3. 核對樓宇與地面的接合，完善瀏覽操作。
4. 檢查準確度、效能及回歸測試結果。

建築細節與故事內容屬於後續發展方向，須以前述基礎工作和資料核實為前提。
